# 邻里有伴（暂定名）

公开仓库：<https://github.com/Patch-A/neighborhood-companion-demo> · 许可证：MIT

当前阶段：首轮案头调研和两轮模型复核已完成；本地全栈功能版已完成后端 session 隔离、输入校验、错误边界、主流程、确认/取消、家人文字卡、陪伴定制、安全演示、规则建议，以及按 UI/UX 方案完成的“今天 / 活动 / 家人 / 我的”场景化前端改造、素材接入和移动视口检查。当前进入投稿材料准备阶段；用户访谈、真实社区供给、真实老人可用性测试和支付宝正式接入仍未开始。

面向低识字、听力障碍及沟通不便老人的邻里活动与家人沟通服务规划。

本仓库目前是项目规划和研究记录，不是已上线产品。参赛原型先验证一个可交付结果：老人能以自己可用的方式看懂模拟活动信息、表达参加意愿、完成本人确认，并看到明确标注的演示状态。前端使用本地轻量 SVG 场景素材，页面文字、按钮和状态仍由 HTML/JS 控制。状态只保存在服务进程内的浏览器 session，重启服务即清空。公开资料支持服务背景和风险边界，但尚未证明老人本人愿意使用某种具体交互，也没有证明真实活动或家属会实际回应。
