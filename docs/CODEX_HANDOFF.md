## 产品目标和已确定约束

用户主要是中国老人：可能会微信但怕复杂程序、能接电话但基本不打字。语音必须保留；文字为选填，兼容系统输入法中的手写、五笔。联系人应在首页突出，由家人预存电话；拨号需用户主动触发。

求助先找家人。家人没空后，低/中风险事项经家人判断，可再交给经过平台验证的附近义工。下棋、广场舞、散步等轻活动可探索附近预约；远途旅游、付费及敏感事项需要家人协同辨别。真实义工入驻必须有平台核验，不能自报“已认证”。图片求助及双方回应要完整；视频暂缓。

支付宝小程序尚未创建。当前没有自有域名、备案域名或国内云服务器；独立部署和国内访问方案尚待选择，不要把 GitHub 源码同步写成已解决国内访问。

## 已实现的演示

- 首页联系人、首选/备用电话号码、本机保存、确认拨号与复制。记录服务失败时仍能打开本机联系人页。
- 点击开始/结束录音，最多 60 秒，试听/删除/重录；不包含语音转文字或自动播放。
- 图片最多 3 张，每张不超过 8 MB，支持 JPEG/PNG/WebP，预览及大图。音频与图片存入当前浏览器 IndexedDB，未上传。
- 求助和回复草稿保存在本机；关闭弹窗和保存失败保留草稿。
- 同一浏览器切换老人/家人/义工演示角色，语音或文字回应；没有真实推送或真实家庭账号。
- “已查看”“已接下”“等待老人确认”“已完成”区分；老人表示没解决可重新处理。
- 付费、远途、敏感事项禁止转派，未确定风险先交家人判断。规则不是完整风险识别系统。
- 首次加载空状态修复；设置表单不被轮询覆盖；弹窗打开暂停轮询；媒体组件保持稳定。

## 依赖安装、检查和本地预览

Node.js >= 22.13.0，pnpm 11.25.0。安装对应版本的 pnpm 后执行：

```sh
cd site
pnpm install --frozen-lockfile
node --test scripts/care-app-loading.test.mjs scripts/help-workflow.test.mjs
pnpm exec tsc --noEmit --incremental false
pnpm build
```

2026-10-10 源工作区的 23 项自动检查、类型检查与构建已通过。本次同步恢复了该版本文件并核对完整性，未重新安装依赖或运行构建。GitHub 新克隆后的依赖下载和不同操作系统运行尚未验证，不能保证所有电脑立即可用。`install:ci` 是 Sites 管理环境脚本，依赖 Linux 工具，不作为 Windows 普通用户安装入口。

干净克隆没有 `.sites-runtime/execution-profile.json`，脚本默认选择 portable 模式。本地开发入口是 `pnpm dev`，默认端口 5173；框架配置包含本地模拟认证及 D1 占位配置，本地模拟认证不可作为线上账号系统使用。

构建成功后，可通过本地 Wrangler 初始化演示数据库，再启动本地构建预览（在 `site/` 执行）：

```sh
pnpm exec wrangler d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_sturdy_tag.sql
pnpm start
```

SQL 是首次初始化用，已有数据库不要重复执行。`pnpm dev` 与构建预览可能使用不同本地存储路径，不能假定两者数据共享；若开发预览出现缺表，先核对其 Wrangler 配置和存储目录，再对同一绑定执行迁移。以上数据库预览步骤作为接手配置指引，尚未在独立 GitHub 克隆环境实测。

## 数据和托管边界

D1 的 `care_sessions` 按 HttpOnly Cookie 隔离当前浏览器会话，用 revision 防止过期写入；附件只有引用，没有文件内容。请求 actor 只能约束演示流程，不能当作身份认证。

线上 D1 数据、本机联系人、录音/照片和草稿不会随 git clone 迁移。本次未导出真实运行状态、访问令牌、缓存、`.env*`、依赖、构建产物或 TypeScript 增量缓存。`.openai/hosting.json` 为现有平台项目配置，不是凭据；保留用于理解原托管配置，不能用来自动复制站点、权限和数据库。

当前网站仍受 Sites 私密访问限制，本次未启用 GitHub Pages，未更改仓库现有公开属性。此应用有 Workers/D1 后端，不能直接把源代码放到静态 Pages 就获得完整服务。

## 下一阶段建议

1. 先做真机可用性验证：安卓/iPhone、微信/支付宝内置浏览器，麦克风拒绝/中断、照片、拨号、手写/五笔、大字和弱网。记录实际结果，不以自动测试替代。
2. 做真实家庭绑定与服务端权限：老人和家人独立账号、邀请绑定、明确的求助接收对象。先打通一家人的完整闭环，再扩展平台义工。
3. 接入私密媒体上传与访问控制，让老人录音/照片可被另一个设备的家人读取；上传失败和收听状态应有清晰反馈。
4. 接入真实通知和收件确认，区别“请求已保存”“已送达”“家人已接下”；电话是否接通不由网页猜测。
5. 评估独立托管或支付宝小程序后端方案，落实中国用户可访问的部署路径；微信/支付宝通讯录、通知与通话能力需按官方接口逐项核验。
6. 平台义工核验、家人转派授权及位置最小化，按阶段接入。持续定位、陌生人匹配、付款和视频尚不开放。
