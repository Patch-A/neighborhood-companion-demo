## 两种实现的边界

| 能力 | 独立本地H5（当前投稿包） | Sites第6版家庭候选 |
| --- | --- | --- |
| 运行与访问 | Node本机HTTP；无云账号或ChatGPT登录 | 已部署私密站点；保留原访问门槛 |
| 身份 | 同一标签页手动切换虚构角色 | 可信Sites用户及服务端家庭成员权限 |
| 消息 | 当前标签页模拟收发/打开/撤回/未理解回应 | D1消息、明确接收者和回执，需主动打开页面 |
| 照片 | 浏览器压缩与sessionStorage，不上传 | R2私密媒体与访问校验 |
| AI | 本地后端实际请求DeepSeek；须配置自己的密钥 | 已配置的Sites后端；不随源码/ZIP分发密钥 |
| 存储 | 标签页演示记录、服务端用量计数 | 平台数据库/对象存储；不随clone迁移 |
| 外部评审 | 本机地址不可远程访问；须确认ZIP交付条件或补公网URL | 当前仅所有者访问，不能直接当成已授权评审入口 |

本地后端流程：页面确认文字 → 同源/token/长度/限额校验 → DeepSeek JSON建议 → 固定图卡词表校验 → 保留原文 → 人工检查 → 用户确认演示发送。失败可手选，模型不接收照片或消息历史。具体配额/数据期限见local-demo/README，不把次数当作人民币预算。
