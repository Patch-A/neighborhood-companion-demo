## 已实现

1. 根路径改为家庭沟通界面，首页四张主要图卡；显示熟悉的家庭成员、优先显示新消息。图卡含义仍需家庭共同确认。
2. 家庭绑定使用可信 Sites 登录身份，邀请指定角色、一次使用、48小时过期；角色与权限由服务器保存。前端 actor 不能提升权限。
3. D1 新增家庭、成员、邀请、消息、媒体、反馈和 AI 用量表；R2 存储私密附件，接口校验家庭与发送/接收权限。已在部署后数据库概览核对全部8张表存在。
4. 两个独立测试身份真实调用接口收发消息与附件；发送按 clientId 去重；收到、打开、回应分开。打开不代表理解，支持“没看懂”回应；未加入后台通知。
5. 家人可以发照片、图卡与可选语音。草稿按家庭/账号隔离、恢复前明确选择；发送失败保留、重试不重复发送。AI 草稿恢复后重新要求检查。
6. 撤回、邀请撤销、反馈、成员退出、家庭删除与附件清理。过期附件停止访问；物理文件在家庭访问时分批清理，没有无人访问时自动执行的定时清理。
7. DeepSeek JSON 图卡候选、已知词表校验、人工确认和手选回退；模型只接收主动提交的文字，照片、语音和完整历史不自动传给模型。
8. 已获准访问的登录用户，在设置家庭前可试 AI 候选，不创建真实家庭或发出消息。每账号每天5次，家庭场景每天20次，站点共用每天200次上限，失败也计入。
9. `/demo` 等历史生活互助界面保留，`/?demo=1` 为独立虚构图卡演示；演示不使用真实身份，不上传附件，不调用模型。

## 实施中的环境修复

- Sites安装 helper 调用旧bash脚本，本机WSL不可用；使用相同pnpm锁文件的标准安装完成依赖。
- Git Windows schannel握手失败，改用本仓库OpenSSL后成功推送；证书验证未关闭。
- 官方打包 helper 需要bash，使用已安装Git Bash；GNU tar的Windows盘符通过 `TAR_OPTIONS=--force-local` 处理，保留原helper与包校验。
- 本地Worker拒绝请求后未读完请求体会影响下一次提交；增加有界读取/丢弃并用拒绝后恢复测试验证。未用重试掩盖失败。
