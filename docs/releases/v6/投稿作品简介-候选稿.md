# 邻里有伴 · 和家人换个方式说话

本文是与 2026-10-13 候选版本一致的材料草稿。DeepSeek 配置与本机实际调用已完成，目标用户测试、线上完整流程及评审访问仍未完成，不作为“已达到投稿目标”的证明。

## 回应的愿望

回应“解决孤独老年人的陪伴问题”。项目聚焦不便通过文字或听觉交流的老人与熟悉家人之间的日常表达与回应，探索熟悉照片和固定图卡是否能帮助双方沟通。

## 本版提供什么

家人设置家庭、放入熟悉照片并邀请参与者。老人选择少量图卡表达心意，家人在自己的账号接收，使用图卡、照片或可选语音回应；老人可以明确表示“没看懂”，继续沟通。消息区分保存、到达设备和打开，不把已查看写成已经理解。

家庭成员与附件权限由服务端校验，照片和语音放在私密存储。同一条消息重试去重；支持撤回、反馈、退出与资料删除。家庭双方需主动打开网页查看，本版没有短信或后台推送。

## AI 场景

家人输入一句话，模型在固定图卡词表内选择候选组合，家人检查、修改并确认后发送。模型不会代替家人作出承诺，也不会根据图卡推断老人同意。无法表达的内容、未知图卡、服务失败退回手选。

使用 DeepSeek 的结构化输出，已完成调用接口、边界处理和两次应用函数真实调用。合成输入“我想看看家人的照片”返回 `photo` 图卡，“请帮我支付医药费用”无法用已有词表表达而退回手选。此结果不等于目标用户效果验证；上线后仍需录制家庭界面的实际运行与纠错实例。

## 演示方式

1. 进入运行网址的 `/?demo=1`，明确使用虚构资料。
2. 示例老人选择“想见你”，确认发给示例家人。
3. 切换示例家人，打开消息并选择图卡回应。
4. 切换示例老人查看回应，演示“没看懂”后继续沟通。
5. 真实双端体验需两个有站点访问权限的独立账号；演示角色切换不等于真实家庭双端。

## 已知边界

固定图卡尚未经过目标老人理解测试，不能宣称适用于所有老人或已经减轻孤独。当前保留 Sites 所有者访问范围，评审访问安排仍需落实。平台义工、真实活动运营、视频、实时手语识别与支付宝正式小程序接入放在后续。
