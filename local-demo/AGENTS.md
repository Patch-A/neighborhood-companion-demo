# 独立本地投稿演示

- 本目录是独立本地H5，不修改或发布现有Sites站点。运行仅需Node.js 22.13+，建议24 LTS，无第三方运行依赖。
- 图卡和模型处理规则复用 `site/` 第6版，由 `scripts/export-site-assets.mjs` 生成固定JS模块和SVG；不要引入Sites身份或数据访问。
- 示例老人/家人是同浏览器演示，不能当作真实家庭认证或双端服务。模型内容必须人工检查再发送演示消息。
- 默认只绑定127.0.0.1，不允许以本目录作为公网家庭服务。密钥、模型输入和照片不写日志，不提交 `.env.local` 或 `data/`。
- 每轮验证本地HTTP、安全边界、模型回退、配额持久化及浏览器主流程；真人测试暂缓并注明。
