# 邻里有伴 · 独立本地H5

本地运行不需要腾讯云、ChatGPT登录或下载前端依赖。图卡和绘图复用Sites第6版，模型调用复用同一校验/请求函数；不修改原站点。此目录可独立复制、解压运行，无需旁边存在 `site/`。

## 一分钟启动

1. 安装 Node.js 24 LTS（最低22.13）：<https://nodejs.org/>。本机已具备Node.js24。
2. Windows双击 **start.cmd**，保持终端窗口打开。
3. 用浏览器打开终端显示的 **http://127.0.0.1:3133**。停止时回到终端按Ctrl+C。

macOS/Linux或命令行：

```sh
cd local-demo
node server.mjs
```

不需要 `npm install` 或 `pnpm install`。如端口占用，关掉上次服务，或在本目录 `.env.local` 设置 `PORT=3134`，再按终端实际网址打开。不要直接双击 `public/index.html`，浏览器需要本地HTTP模块和后端。

## 配置DeepSeek（可选）

不配置时，手选图卡、示例收发、未理解回应、照片和大字模式仍可用，AI入口明确显示未配置。

Windows双击 **configure-ai.cmd**：仅当 `.env.local` 不存在时复制空白模板，然后用记事本打开。将你自己的DeepSeek API密钥填在 `FAMILY_AI_API_KEY=` 后，保存后重启服务。它不会覆盖已有配置。不要把密钥发到聊天、写进页面或提交GitHub。

其他系统复制 `.env.example` 为 `.env.local` 并在本机编辑：

```dotenv
FAMILY_AI_API_KEY=在本机填写，不分享
FAMILY_AI_MODEL=deepseek-flash
PORT=3133
```

已有 `FAMILY_AI_API_KEY` 进程环境变量也可使用，优先于配置文件；没有专用配置时可读取本进程已有 `DEEPSEEK_API_KEY`，不复制或显示其值。本服务不会搜索其他项目的凭据。模型地址固定为DeepSeek官方HTTPS接口。

展开“补充照片、文字，或请AI帮忙”，输入不含真实隐私的示例文字，确认第三方处理，再点击建议。AI只建议最多3张固定图卡，原文保留；核对勾选后才能发送演示消息。无法表达、模型异常或连接超时都保留原文并可手选，不用规则冒充AI。修改原文会作废旧AI图卡，恢复AI草稿也重新要求核对。

## 演示一次完整往返

1. 示例老人选择“看看照片”，确认发送。
2. 手动切换“示例女儿”，点击打开消息。
3. 点击“没看懂，请再说说”，再确认发回。
4. 切回示例老人，打开回应，选择另一张图卡或添加本机照片，再确认发送。
5. 需要展示AI时，示例女儿输入“我想和家人一起出去走走”，请DeepSeek建议并核对。

每一步都由体验者操作；没有自动伪造家人回应或理解。收到/打开不等于理解。两种角色只是本机示例，不是两个真实账号。

## 资料与费用边界

- 只监听127.0.0.1；局域网手机或外部评审不能直接访问这个网址。本版不提供公开认证、真实家庭权限、跨设备消息、后台推送、录音或支付宝小程序接入。不要做端口映射公开它。
- 消息、双方草稿和照片存当前标签页的sessionStorage；刷新恢复，通常关标签页后清除，浏览器恢复会话可能保留。24小时外消息在下次恢复时丢弃，最多60条。没有把演示资料写入服务端家庭数据库；点“重置演示”清空本页资料，但不清除模型配置或用量。
- 每张照片原文件最多8MB；在浏览器缩到最长640px、转成JPEG，最多约600KB数据字符串；不上传到本地服务器或模型。浏览器空间不足会明确提示本页未持久化。
- 模型只接收主动提交且确认的文字，不接收照片或完整演示记录；实际联网请求仍消耗用户DeepSeek账户额度，非离线AI。
- 本服务实例每日最多200次模型尝试（北京时间）、每分钟10次、最多2个并发；失败也计入。次数写入本目录 `data/usage.json`，重启不重置当日配额。不要用多个实例共享同一data目录；不同目录副本的限额各自独立，不是账号总额或人民币硬预算。不要删除用量文件来回避限额。配额文件损坏时拒绝启动，先保留检查，避免偷偷重置。
- 服务端验证Host、同源与本机页面token，静态文件白名单阻止读取配置；不记录密钥、输入文本、模型原始输出或照片。无云资源费，计算机与模型请求费用另计。

## 检查与维护

```sh
node --test tests/*.test.mjs
```

测试用临时目录、随机loopback端口和受控模型替身；不读取真实配置、不付费调用、不使用生产或真实家庭资料。包括提示解析、未配置、同源/密钥隔离、限额持久化与拒绝后恢复等。浏览器主流程与真实AI实调结果见交付记录，不能用替身测试当作真实模型或真人效果证明。

开发时如需重新导出图卡/模型模块，在仓库保留原 `site/` 及其pnpm11.25.0锁定依赖后执行：

```sh
node local-demo/scripts/export-site-assets.mjs
```

运行不依赖此导出过程或编译器。更改导出文件应从原模块修正，保持固定词表/提示词/绘图一致。生成文件纳入源码和独立交付包，依赖/真实 `.env.local`/`data/` 不纳入。
