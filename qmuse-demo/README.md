## QMuse 云服务与限额

一张 `ai_quota_slots` 表只保存用量范围和到期时间；不保存文字、照片、原始网络地址、原始访客ID或模型密钥。一个 `card-suggestion` 云函数提供状态和模型候选，使用平台会话身份，并通过确定性的唯一行ID预留限额。最多本应用/环境50次/北京时间日、10次/分钟；同一平台访客身份5次/日、2次/分钟。更换访客身份可以重置个人次数，全站上限不变，不把匿名身份当家庭认证。

失败及部分预留也消耗次数，不回滚预留以避免并发超用；用量持久化，重新发布不应重置。访问已启用AI的状态时每次最多清理50条过期行，约三天后可清理；无人访问时没有定时清理。开发、生产与现有 Cloudflare 用量分别计算，不是整个模型账号的金额预算。

模型固定使用既有 DeepSeek 服务和固定图卡解析，12秒超时，不跟随重定向；没有密钥时明确显示AI未开放。真实第三方密钥只能经本人同意后为此新应用通过官方密钥管理设置，不能放源码、前端、公开配置、环境示例或日志。

**启用AI前必须核对真实权限**：平台新表默认 READ=ALL、SUBMIT=ALL、EDIT=CREATOR、DELETE=CREATOR，不适合可信全局用量。应在产品的“数据表权限设置”将 `ai_quota_slots` 的读/提交/编辑/删除均限制为应用管理员，公众通过云函数取得聚合用量；仅云函数最小服务权限可预留行。不得用代码中的隐藏按钮或伪造 auth/schema 配置替代表权限。权限未实际设置、匿名验收未通过时，不配置模型密钥/不开放AI。

函数所需权限限于表读写，执行入口可供公开访客使用，但每次模型调用必须有平台注入的访客会话、有效输入、主动同意和成功用量预留。记录一次真实模型候选与一次无法表达内容的回退；只有真实发布及验证成功后才更新投稿材料。
