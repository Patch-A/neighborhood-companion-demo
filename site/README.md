# 邻里有伴

## 2026-10-13 家庭图卡沟通候选版

根路径 `/` 现为家庭图卡沟通；`/?demo=1` 是与真实资料隔离、仅在当前页面保存的演示。`/demo`、`/requests` 等保留历史生活互助演示。继续保留现有 Sites 访问范围，没有创建支付宝小程序、公开 GitHub Pages 或真实外部通知。

当前已实现：

- 固定图卡、家庭照片、消息往返、没看懂的图卡回应、大字模式和发送前确认。图卡含义尚未经过目标老人验证。
- 使用可信 Sites 登录身份建立家庭；一次性邀请绑定角色，48 小时过期，最多 6 人。请求里的 actor/role 不能覆盖已经绑定的身份。
- D1 家庭与消息记录、R2 私密照片/语音；附件接口按成员与消息接收权限校验。每份 8 MB、最多 3 张照片与 1 段语音；同家庭最多 100 份附件、1000 条消息、每小时最多 100 条发送。
- 消息区分“已保存”“到达设备”“对方打开”；打开不代表理解，不自动生成家人回复。没有后台推送，双方需主动打开网页。
- 草稿按家庭与账号隔离，恢复前明确选择；发送失败保留内容、同一 clientId 重试去重。未发送本机媒体在发送时检查 24 小时期限。
- 自己的消息可撤回，家庭内可提交/查看反馈，邀请可撤销，成员可退出并清理相关资料，家庭创建者可删除家庭资料。撤回不能收回对方已看见的内容。
- AI 图卡候选接口、固定词表校验、人工确认、手选回退。用户指定 DeepSeek，已在 Sites 配置 secret 与 `deepseek-flash`；应用使用的同一模型调用函数已完成两次本机真实调用，照片表达返回 `photo`，不支持的敏感意图返回手选回退。演示模式不调用 AI，线上家庭完整路径仍需发布后实测。

### AI 接入

由 Sites 的环境变量工具配置以下三项，密钥标为 secret；不要将值写进仓库或前端。

- `FAMILY_AI_BASE_URL`：HTTPS 的兼容 Chat Completions 服务基础 URL，例如服务的 `/v1` 地址；代码追加 `/chat/completions`。
- `FAMILY_AI_API_KEY`：模型服务密钥。
- `FAMILY_AI_MODEL`：服务支持的模型名。

模型须支持 JSON 输出。输入最多 500 字，只处理家人主动提交的文字，不自动上传录音、照片或全部家庭历史。用户点击前说明第三方处理；模型只能建议已有图卡，不发送消息。每家庭每天最多 20 次，站点每天最多 200 次，失败调用也计入限额。此次数限额不等于已核定人民币预算；实际费用、提供方与地域可用性需选择服务后确认。

获准访问站点的登录用户在设置家庭前，可展开“先试一试 AI 图卡建议”。这个入口不需要创建真实家庭，每账号每日最多 5 次，仍受站点每日 200 次上限约束，不接触任何家庭资料或发送接口。

2026-10-13 配置为 `https://api.deepseek.com` 与 `deepseek-flash`，并按官方文档关闭思考模式以获取短 JSON 候选。来源：[JSON Output](https://api-docs.deepseek.com/zh-cn/guides/json_mode/)、[思考模式](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)。实际服务检查可手动执行 `node scripts/deepseek-smoke.mjs`；它从进程环境读取现有密钥，只发送合成输入，不记录密钥，不属于自动测试套件。

如选择 OpenAI，按 Sites 技能要求通过 OpenAI Developers 插件的 API key 技能获取/配置，不能自行从其他项目复制密钥。

### 保存期限与清理

消息、已发送附件与反馈 30 天后停止展示/访问；未发送的服务端附件 24 小时过期。头像保留到移除、退出或家庭删除。家庭读取时分批清理 R2 过期/撤回文件；没有无人访问时也定时运行的清理任务。删除整个家庭会撤销访问并清理文件；清理失败可以重试。同浏览器的本机草稿需另行清空，清浏览器资料也会删除本机草稿。公开试用前应根据保存承诺补充定时清理方案。

## 历史生活互助演示说明（仅适用于 `/demo` 等旧页面）

以下能力与存储边界属于旧演示，不适用于上述新家庭接口。

## 当前可体验

- 首页：本机预存的首选/备用联系人、手机拨号入口、说话求助、拍照求助及大字入口。
- 求助：点击开始/结束录音（最多 60 秒），试听、移除重录；拍照/选照片（最多 3 张，每个附件不超过 8 MB），预览及大图；文字选填。
- 求助与回复草稿在此浏览器保存。关闭弹窗保留草稿，服务端保存成功后移除草稿；附件不上传，保存在 IndexedDB。浏览器存储被清理、换浏览器或换设备后，附件无法恢复。
- 同一浏览器的家人/义工演示角色可语音或文字回应。没有自动生成的假家人回复。
- 已查看不代表已接下；处理完成进入 awaiting_confirmation，老人确认后进入 completed；还没解决可重新接下；家人暂时没空仍可继续处理或核对风险后模拟转派。
- 付费、远途、敏感事项不转派；未确定的事项默认需家人核对。规则不是完整风险识别，不替代人工判断。
- 个人设置只在首次载入初始化，不被定时刷新覆盖；录音与表单组件不因父层更新重建。弹窗开启时暂停轮询。
- 底部导航为首页/消息/我的；联系人、记录和演示角色切换位于“我的”。无网络或记录服务失败时，本机联系人页仍可打开。
- 保留原有个人资料、陪伴便签和示例活动入口；重置需确认，清空演示记录、本机附件和草稿。电话号码通过联系人页单独确认清除。

## 存储与边界

D1 延续 care_sessions，按 HttpOnly Cookie 隔离演示记录，修订号防止过期写入；没有改数据库表或历史迁移。D1 仅保存附件引用，不保存文件内容。本机联系人不上传，不等于真实家庭账号绑定。

请求中的 actor 仅约束演示操作，不能当作身份认证。正式版必须新增真实账号、家庭关系与服务端权限。R2/私密文件访问、跨设备同步、真实通知、平台义工验证均留待下一阶段。

电话由用户主动确认后调用 tel: 链接，是否支持由手机和浏览器决定。无法知道是否接通，不会自动确认求助完成。不是应急救援或医疗服务。

录音依赖安全页面、浏览器 MediaRecorder/getUserMedia 和用户麦克风授权。不提供语音识别、自动外放、AI 自动执行或视频。拒绝权限或设备不支持时保留照片、文字和电话路径。
