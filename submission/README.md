## 提交前还需要你确认

运行包不含密钥：不配置仍能体验手选/图卡往返；AI实试需要运行者在本机配置自己的DeepSeek API密钥，并从其账户计费。不能承诺评审必然会自行配置；若评审不能这样体验，须另行提供可授权访问且能实际运行AI的服务。当前127.0.0.1地址仅供本机，既有私密Sites也未授予评审访问。

本人姓名、实名/联系信息、最终作品权利声明及提交由本人按表单填写，不放入公开材料。不要把任何密钥、真实照片或家庭资料附在作品包里。
